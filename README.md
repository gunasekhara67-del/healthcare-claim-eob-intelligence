# Healthcare Claim & EOB Intelligence Automation

## Objective
Analyze healthcare claim and EOB information and produce structured business summaries.

## Flow
Claim/EOB CSV → Pandas preprocessing → Structured prompts → LLM analysis → Validated output → Dashboard

## Skills
Python, Pandas, NLP, Prompt Engineering, LLM, Gemini API, Streamlit.

## Run
`pip install -r requirements.txt`
`streamlit run app/app.py`

Use synthetic/de-identified data only. Never commit API keys.
